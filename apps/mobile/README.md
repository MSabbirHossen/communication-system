# @cs/mobile — Capacitor shell

Android and iOS apps are a Capacitor 8 wrapper around the web client (`apps/web`): the same matrix-js-sdk and Rust crypto WebAssembly run in the platform WebView (ADR-0001 C2, ADR-0006). The native projects (`android/`, `ios/`) are generated by the Capacitor CLI and committed; the web bundle is copied into them at build time and is not committed.

## Build

```bash
pnpm --filter @cs/mobile build:web
```

Builds the web client (homeserver and API URLs from `VITE_HOMESERVER_URL` / `VITE_API_URL`, defaults `http://localhost:8008` / `http://localhost:3000`, which also set the page's `connect-src`) and runs `cap sync` for both platforms. Set `CS_MOBILE_VARIANT=debug` for a build that may talk to a plain-http development homeserver (see `capacitor.config.ts`); the default is the release variant (https only).

The development machine has no Android SDK or Xcode. Native builds run in CI (`.github/workflows/mobile.yml`): the Android job uploads a debug APK to sideload, the emulator job runs the device spike, and the iOS job builds and runs the simulator on a macOS runner. See `docs/runbooks/local-development.md` §11.

## Variants and security posture

- Release: bundle served from `https://localhost`; no cleartext; `android:allowBackup="false"`; CSP `connect-src` limited to the configured origins.
- Debug: Android bundle served from `http://localhost` (still a secure context) and cleartext allowed by the debug build type only; iOS keeps `capacitor://localhost` and allows local-network cleartext through `NSAllowsLocalNetworking`.
- The session (tokens) lives in native secure storage (Keystore / Keychain) through `@aparajita/capacitor-secure-storage`; the recovery key is never stored by the app; the SDK's sync and crypto stores stay in the WebView's IndexedDB inside the app sandbox without hardware-backed key protection (THREAT_MODEL TM-23, disclosed in the privacy notes).
- Push: pusher registration is content-free (`event_id_only`); delivery needs FCM/APNs credentials provided as secrets later (never committed). `google-services.json` is absent and the build tolerates that.

## Plugins

`@capacitor/app` (lifecycle, back button) and `@aparajita/capacitor-secure-storage` (tokens). No others.
